3. 7단계 설치 안내서: 서버 앞에 프록시를 두면 기기별 잠금이 하나로 묶인다는 점, 서버 QR 보관

## 이 PC에서 앱을 직접 보는 방법 (데모)
- 데모 서버: `server/`에서 `MILKBANK_DB=data/demo/m.db uv run milkbank-serve` (데모 계정은 `server/data/demo/demo-accounts.txt`, git에 안 올라감)
- 에뮬레이터: Android Studio의 Device Manager에서 `Medium_Phone_API_37.0` 실행 → 앱 설치(`android/`에서 `gradlew installDebug`) → 등록 화면의 **[테스트용 서버로 등록 (개발용)]** (`qr.txt`는 `server/data/demo/qr.txt`를 기기의 `/sdcard/Android/data/app.milkbank/files/qr.txt`로 넣기)
- 처음 실행 시 '근처 기기' 권한을 허용해야 서버에 연결됩니다 (Android 17).
