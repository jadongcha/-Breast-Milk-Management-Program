# 다른 PC용 서버 실행 파일 — 설계 (짧은 설계)

- 날짜: 2026-11-15
- 상태: 확정 (사용자 승인 "어 해봐", 데모 자료 포함으로 변경)

## 목적
- 사용자 요청: 이 개발 PC를 꺼도 서버가 돌아가도록, **다른 PC에서 서버를 돌릴 수 있는 실행 파일**을 만든다. 핸드폰으로 시험하고, 나중에 병원 서버 PC 설치(7단계)에도 쓴다.

## 방법 (사용자 승인)
- **Python까지 담은 실행 파일 폴더**(PyInstaller onedir) `모유관리서버/`. USB로 옮겨 어디에 두든 동작, Python 설치·인터넷 불필요.
- 버린 방법: 서버 PC에 Python·uv 설치 후 소스 실행(인터넷 필요, 단계 많음).

## 내용
- `milkbank-server.exe` 하나에 하위 명령: `setup-tls --host <IP> [--port]`, `create-admin --username --name`, `serve` (기존 `milkbank-setup-tls`·`milkbank-create-admin`·`milkbank-serve`와 같은 동작). DB·인증서·백업은 폴더 안 `data/`(실행 위치 기준, 기존 `MILKBANK_DB` 기본값과 같음).
- 배치 파일(한글 이름, UTF-8 + `chcp 65001`):
  - `처음설정.bat`: 관리자 권한 확인 → 서버 PC IP 입력(찾은 IPv4 목록을 보여 주고 고르게) → 인증서·등록 QR 생성 → 관리자 계정(아이디 입력, 임시 비밀번호 표시) → **PC가 켜질 때 자동 시작** 등록(작업 스케줄러, 시스템 시작 시, 로그인 없이) → 지금 서버 시작 → 방화벽 8443 허용 방법 안내(직접 허용) → 등록 QR 이미지 열기
  - `서버시작.bat`, `서버중지.bat`, `자동시작해제.bat`
  - 서버 출력은 `data/logs/server.log`에 남긴다
- `읽어주세요.txt`: 옮기는 법, 처음 설정, 방화벽, 핸드폰 앱 등록(QR), 백업 위치, 개인정보 주의
- 만들기: 개발 PC에서 `server/packaging/build.ps1` 한 번 → `server/dist/모유관리서버/`와 `모유관리서버.zip`. 만든 결과는 git에 넣지 않는다.

## 결정 (Claude)
- 대상: Windows 10/11 64비트.
- 방화벽 규칙은 만들지 않는다(보안 설정은 사람이 직접). 안내만.
- 자동 시작은 관리자 권한이 필요하므로 `처음설정.bat`가 권한이 없으면 "관리자 권한으로 실행" 안내 후 멈춘다.
- **데모 자료를 넣는다**(사용자 요청 2026-11-15 "데모자료가 든걸로해줘"): 빌드가 `모유관리서버-데모/`를 만든다. 지금 이 PC의 데모 DB를 복사하지 않고(시험 흔적이 섞여 있음), 빌드 때 새로 만든다.
  - 새 스크립트 `server/scripts/make_demo_db.py <DB 경로> <계정 파일 경로>`: 최신 마이그레이션으로 빈 DB를 만들고 관리자 `admin`, 간호사 `nurse1`(비밀번호는 빌드 때 무작위로 만들고 바로 쓸 수 있게 — 처음 비밀번호 변경 없음), 아기 DEMO-01~08(보호자 전화번호 010-1234-5601~5608, 병상 1~8), 빌드한 날 기준 지난 14일 동안의 입고(팩별 mL, 일부는 용량 모름)·사용·폐기 기록, 확인 대기 제출 2건을 넣는다. 부족 아기·0팩 아기가 섞이게 한다.
  - 계정 파일 `데모계정.txt`(폴더 맨 위)에 아이디·비밀번호·보호자 로그인 예시를 쓴다. 저장소에는 비밀번호를 넣지 않는다.
  - `처음설정.bat`는 `데모계정.txt`가 있으면 관리자 만들기를 건너뛰고 그 파일을 보여 준다.
  - 실제 병원용(빈 DB) 폴더는 `build.ps1 -Real`로 따로 만들 수 있게 둔다.

## 하지 않는 것
- Linux/Mac용, 설치 프로그램(MSI), 자동 업데이트, 방화벽 자동 설정, 코드 서명

## 확인
- 자동 시험: 하위 명령 분기, 고정된(frozen) 실행에서 마이그레이션 폴더를 찾는지.
- 이 PC에서 만든 폴더를 임시 위치로 복사해 실제로: `setup-tls --host 127.0.0.1 --port 18443` → `create-admin` → `serve` → `https://127.0.0.1:18443/health` 200 → 종료. 자동 시작 등록은 이 PC의 설정을 바꾸므로 실제로 등록하지 않고 명령 문자열만 확인한다.
