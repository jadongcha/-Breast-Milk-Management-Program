# 모유 재고관리 — 2-1단계 서버 보강 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 1단계 서버에 DB 구조 버전 관리(Alembic), HTTPS 인증서와 서버 등록 QR, HTTPS 전용 실행 명령, 직원 로그인 5회 실패 잠금을 더한다.

**Architecture:** 표 만들기(`init_db`)를 `migrate()`로 바꾸고, 서버 앱·CLI·테스트가 모두 이 함수로 DB를 준비한다. 인증서·QR 로직은 순수 함수 모듈 `tls.py`에 두고 CLI(`setup_tls.py`, `serve.py`)는 얇게 감싼다. 로그인 잠금은 `staff.login` 안에서 판정하고, 실패 기록은 API 라우트가 오류를 내기 전에 커밋한다.

**Tech Stack:** Python 3.12+, FastAPI, SQLAlchemy 2, SQLite, Alembic, cryptography, qrcode(PNG, pypng), uvicorn, pytest

**Spec:** `docs/superpowers/specs/2026-11-10-2-1단계-서버보강-design.md` (상위: `docs/superpowers/specs/2026-11-10-모유재고관리-design.md`)

## Global Constraints

- 코드는 `server/`, 명령은 `server/`에서 `uv run ...`. 1단계 테스트 97개는 계속 모두 통과해야 한다. `uv run pytest -W error`로 실행한다.
- 새 의존성은 `alembic`, `cryptography`, `qrcode[png]` 세 개만 추가한다(`uv add alembic cryptography "qrcode[png]"`). 이 명령이 권한 확인에서 거부되면 우회하지 말고 BLOCKED로 보고한다.
- 사용자에게 보이는 메시지는 이 계획에 적힌 한국어 문구를 그대로 쓴다.
- 시각은 UTC로 저장한다. 테스트는 `FakeClock`을 쓴다.
- 라우트는 `DbDep`을 쓴다. DB 변경은 요청 끝에 한 번 커밋되고, 오류가 나면 되돌린다. 예외는 로그인 실패 기록 하나뿐이다(Task 4).
- CLI는 Windows 콘솔에서 한글이 깨지지 않게 `cli._utf8_streams()`를 재사용한다. 오류는 stderr, 종료 코드 1, traceback 없이 낸다.
- 1단계 테스트용 DB(버전 기록 없이 표만 있는 DB)는 열지 않는다.

## Review Focus

1. **서버가 켜져 있는데 관리자 생성 CLI를 실행** — 두 프로세스가 같은 DB에 `migrate()`를 부른다. 이미 최신이면 아무 일도 하지 않고 백업도 만들지 않아야 한다. → Task 1 `test_migrate_twice_is_noop`
2. **WAL 모드에서 아직 체크포인트되지 않은 데이터의 백업** — 파일만 복사하면 `-wal` 파일의 최신 내용이 빠진다. sqlite 백업 API로 복사해야 한다. → Task 1 `test_backup_includes_wal_data`
3. **아이디 대소문자·공백이 달라도 같은 잠금** — `" Admin "`과 `"admin"`의 실패가 함께 세어져야 한다. → Task 4 `test_lock_counts_normalized_username`
4. **`setup-tls`를 주소를 바꿔 다시 실행** — 같은 키를 쓰므로 `pin`은 그대로이고, 인증서에는 새 주소가 들어가야 한다(기기 재등록 불필요). → Task 2 `test_rerun_with_new_host_keeps_pin`
5. **잠금 상태가 실제로 DB에 남는지** — 오류 응답 뒤에 DB 변경이 되돌려지면 잠금이 동작하지 않는다. HTTP로 5번 실패한 뒤 6번째(맞는 비밀번호)가 429여야 한다. → Task 4 `test_lock_persists_across_http_requests`

    - `migrate(engine: Engine, db_path: Path, now: datetime) -> Path | None`

      - 판정 순서:
        1. 파일이 있고 크기가 0보다 크며, `alembic_version` 표는 없고 앱 표(`staff` 등)가 있으면 `LegacyDatabaseError`

        3. 함수를 부르기 전에 파일이 있었고 크기가 0보다 크면, 업그레이드 전에 `backups_dir / f"milkbank-{now:%Y%m%dT%H%M%SZ}-before-{head}.db"`로 `backup_db` 한다.
        4. `upgrade head`를 실행하고, 만든 백업 경로를 돌려준다(없으면 `None`).
      - `backups_dir`는 `db_path.parent / "backups"`이다.
    - `env.py`: `target_metadata = Base.metadata`, `render_as_batch=True`, 넘겨받은 연결을 쓴다(온라인 모드만).
    - `0001_baseline.py`: revision id `"0001"`. 1단계의 모든 표 + `login_attempt` + 위 인덱스 2개. 처음에는 `alembic revision --autogenerate`로 만들고 손으로 검토한다. downgrade는 모든 표를 지운다.
  - `db.init_db` 삭제. `create_app`은 `migrate(engine, config.db_path, app.state.clock.now())`를 호출한다. `cli.main`은 `migrate(engine, path, SystemClock().now())`를 호출하고, `LegacyDatabaseError`면 메시지를 stderr에 쓰고 종료 코드 1로 끝낸다.
  - `tests/conftest.py`의 `engine` 픽스처: `migrate(eng, path, clock.now())`

### Task 2: 인증서·서버 등록 QR과 `milkbank-setup-tls`

**Files:**

**Interfaces:**
- Consumes: `Config.tls_dir`, `load_config()`, `cli._utf8_streams()`
- Produces (`tls.py`):
  - `class TlsError(Exception)` (한국어 메시지)
  - `parse_host(raw: str) -> str`: 앞뒤 공백을 제거한다. IP(`ipaddress.ip_address`) 또는 DNS 이름(라벨 `[A-Za-z0-9-]`, 1~63자, 하이픈으로 시작·끝 불가)이어야 한다. 아니면 `TlsError(f"서버 주소가 올바르지 않습니다: {raw}")`
  - `load_or_create_key(path: Path, new_key: bool) -> tuple[ec.EllipticCurvePrivateKey, bool]`: 반환값은 `(키, 재사용 여부)`. EC P-256, PEM, 암호화 없음.
  - `build_certificate(key, hosts: list[str], now: datetime) -> x509.Certificate`: 자체 서명이다. CN = 첫 주소. SAN에는 IP는 `IPAddress`, 이름은 `DNSName`으로 모두 넣는다. `not_valid_before = now - 1일`, `not_valid_after = now + 3650일`. `BasicConstraints(ca=False)`.
  - `spki_pin(key) -> str`: `"sha256/" + base64(sha256(DER SubjectPublicKeyInfo))`
  - `server_url(host: str, port: int) -> str`: `https://{host}:{port}`. IPv6면 `https://[{host}]:{port}`.
  - `qr_payload(url: str, pin: str) -> str`: `json.dumps({"type": "milkbank-server", "v": 1, "url": url, "pin": pin}, separators=(",", ":"))`
  - `write_qr_png(payload: str, path: Path) -> None` (qrcode PNG)
  - `@dataclass SetupResult(url: str, pin: str, qr_path: Path, key_reused: bool)`
  - `setup_tls(tls_dir: Path, hosts: list[str], port: int, new_key: bool, now: datetime) -> SetupResult`
    - `hosts`가 비어 있으면 `TlsError("서버 주소(--host)를 하나 이상 입력해 주세요")`
    - 포트가 1~65535가 아니면 `TlsError("포트 번호가 올바르지 않습니다")`
    - `server.key`, `server.crt`, `server-qr.png`, `server.json`(`{"hosts": [...], "port": n, "url": url, "pin": pin}`)을 쓴다.
- `setup_tls.main()`: argparse로 `--host`(여러 번, 필수), `--port`(기본 8443), `--new-key`를 받는다. 출력:
  - `서버 주소: {url}`
  - `인증서 확인값: {pin}`
  - `서버 등록 QR: {qr_path}`
  - `이 QR을 출력해 신생아실에 보관하세요`
  - 새 키를 만들었고 기존 키가 있었다면 `"인증서 키를 새로 만들었습니다. 모든 기기에서 서버 등록 QR을 다시 찍어야 합니다"`
  - `TlsError`는 stderr에 쓰고 종료 코드 1.
