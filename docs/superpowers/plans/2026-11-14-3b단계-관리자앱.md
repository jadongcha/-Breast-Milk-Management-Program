# 3b단계 관리자 앱 + mL 입력 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 앱에 mL 선택 입력·표시, 관리자 전체 현황, 일별 사용량·그래프·CSV 저장, 설정 화면, 퇴원 처리·개인정보 말소, 서버 설정값에 따른 직원 자동 로그아웃을 더한다.

**Architecture:** 기존 패턴을 따른다: Retrofit `MilkbankApi` + `data/*Repository`(`ApiResult`) + 화면마다 `ViewModel`(StateFlow) + Compose 화면, 경로는 `ui/StartDestination.kt`의 `@Serializable` Route와 `AppNavHost`. 관리자 메뉴는 `PatientsPane`의 더보기 메뉴(관리자만). 새 화면은 `ui/admin/` 아래. 그래프는 Compose `Canvas`로 직접 그린다(라이브러리 추가 없음).

**Tech Stack:** Kotlin, Jetpack Compose (Material3), Retrofit + kotlinx.serialization, coroutines; JVM 테스트 JUnit + coroutines-test + turbine; 화면 테스트 compose-ui-test.

**Spec:** `docs/superpowers/specs/2026-11-14-3단계-관리자기능-design.md` (서버는 3a 계획 `2026-11-14-3a단계-관리자서버.md`로 완료)
