# 2-3b 제출처 앱 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 2-3a 서버 API를 쓰는 앱 기능을 더한다.
- 관리자가 태블릿을 **제출처 모드**로 바꾸고 제출처를 관리한다.
- 보호자가 그 태블릿에서 재고를 보고 가져온 모유를 제출한다.
- 간호사가 홈의 **입고 확인 대기** 표에서 확인하거나 반려한다.

**Architecture:** 기존 2-2 앱 구조를 따른다.
- **API와 저장소:** Retrofit `MilkbankApi`에 엔드포인트를 더하고, `Repositories`에 저장소 인터페이스 3개(`StationRepository`, `GuardianRepository`, `SubmissionRepository`)와 Http 구현을 더한다.
- **제출처 정보 저장:** `StationStore`(DataStore + Android Keystore AES-GCM)에 저장한다. `AppContainer`가 들고 있다.
- **제출처 모드:** 시작 화면과 화면 이동 보호 규칙이 `GuardianHome`만 보여 주게 한다.
- **보호자 흐름:** 화면 하나(`GuardianHome`) 안에서 `GuardianViewModel` 상태로 단계가 바뀐다. 1분 무조작 타이머는 컨테이너가 가진다.

**Tech Stack:** Kotlin, Jetpack Compose Material3, Navigation Compose(타입 안전 경로), ViewModel + StateFlow, Retrofit 3 + OkHttp 5 + kotlinx.serialization, DataStore, `javax.crypto` + AndroidKeyStore. 새 라이브러리는 쓰지 않는다.

**Spec:** `docs/superpowers/specs/2026-11-10-2-3단계-제출처-design.md` 4장(앱), 5장, 6장 앱 부분. 서버 API는 같은 문서 3장과 `server/README.md`. 앱 공통 규칙은 `docs/superpowers/specs/2026-11-10-2-2단계-간호사앱-design.md`.

**Branch:** `feature/stations` (2-3a 서버와 같은 브랜치, 12dea6c 이후)

## Review Focus

1. **보호자가 중간에 자리를 떴다.** 팩 수를 고르거나 확인 창을 연 채로 60초가 지나면 로그아웃해야 한다. 입력칸과 고른 수가 비워진 첫 화면으로 돌아가야 하고, 다음 보호자가 앞사람의 아기 ID나 재고를 보면 안 된다. → Task 5 `idle60s_logsOutAndClearsEverything`
2. **[제출]을 두 번 누르거나 제출 중에 화면을 돌렸다.** 제출은 한 번만 돼야 한다. 상태는 ViewModel에 둔다. → Task 5 `submitWhileSubmitting_isIgnored`
3. **보호자가 재고 화면에 있는 동안 관리자가 제출처를 중지했다.** 다음 동작에서 "등록된 제출처 기기가 아닙니다" 화면으로 가야 한다. 앱이 죽거나 로그인 화면을 오가면 안 된다. → Task 5 `stationInvalid_showsInvalidState`, Task 4 경로 테스트
4. **간호사 확인 중 통신이 끊겼다.** 대기 표를 다시 불러오고 `pending_uncertain`을 보여 줘야 한다. 같은 제출을 두 번 확인하면 안 된다(서버도 409로 막음). → Task 6 `confirmNetworkError_refreshesAndWarns`
5. **제출처 모드에서 앱이 강제 종료됐다가 다시 켜졌다.** 보호자 첫 화면으로 돌아와야 하고, 직원 화면(목록·상세)이 다시 열리면 안 된다. → Task 4 `startDestination_stationMode`, `guardRoute_stationMode`

  - 간호사가 2팩으로 고쳐 확인한다. 결과 띠: "DEMO-01 · 2팩 입고 확인 완료 · 현재 냉동 재고 4팩"
- 작업별 검토에서 고친 것
  - 제출처로 바꾼 직후 로그인 화면으로 갈 수 있던 문제: 제출처 모드 화면 규칙으로 해결
  - 해제 창이 화면 회전 뒤 관리자 로그인을 남겨, 로그인 없이 해제할 수 있던 문제
  - 아기 ID 입력칸 키보드가 ID를 학습해 다음 보호자에게 추천할 수 있던 문제: 학습하지 않는 키보드로 변경
  - 통신이 끊긴 확인의 "처리됐는지 확인하지 못했습니다" 경고가 새로고침에 덮이던 문제
  - 시험용 권한 자동 허용이 개발용 설치 전체에 적용되던 문제: 시험 안에서만 허용
- 최종 검토에서 고친 것
  - **보호자 세션 유지:** 서버는 마지막 요청 60초 뒤 보호자 세션을 끝낸다. 보호자가 화면을 만지며 1분 넘게 고르면 제출이 사라질 수 있었다. 30초가 지나면 단계마다 서버에 한 번 물어 세션을 이어 가고, 그래도 끝났으면 "시간이 지나 처음 화면으로 돌아왔습니다"를 보인다.
  - **해제 창 시간 제한:** 관리자가 해제 창에 로그인한 채 1분 동안 조작이 없으면 닫고 로그아웃한다.
  - **관리자 로그아웃:** 제출처 전환·해제 때 관리자 로그아웃을 서버에도 알린다.
  - **제출처 토큰 저장 안정화**
    - 확실한 복호화 실패일 때만 지운다.
    - 키 생성은 한 번만 한다.
    - 복호화는 메인 스레드 밖에서 한다.
    - 저장값을 지우다 오류가 나도 앱이 멈추지 않는다.
  - README: 임시 비밀번호인 관리자는 해제 전에 비밀번호를 바꿔야 한다.

  - 빈 대기 표는 숨기지 않고 "확인할 제출이 없습니다"를 보인다.
