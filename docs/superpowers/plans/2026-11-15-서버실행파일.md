# 다른 PC용 서버 실행 파일 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Python 없이 다른 Windows PC에서 서버를 설정·실행·자동 시작할 수 있는 `모유관리서버/` 폴더(와 zip)를 만든다.

**Architecture:** 하위 명령 분기 모듈 `milkbank/launcher.py`를 PyInstaller onedir로 묶는다(`milkbank-server.exe`). 마이그레이션 폴더(`milkbank/migrations`, .py와 .mako)는 데이터 파일로 함께 넣는다. 배치 파일과 안내문은 `server/packaging/`에 두고 빌드 때 복사한다.

**Tech Stack:** Python 3.13, PyInstaller(빌드 때만 `uv run --with pyinstaller`), Windows 배치, PowerShell 빌드 스크립트

**Spec:** `docs/superpowers/specs/2026-11-15-서버실행파일-design.md`

## Global Constraints

- 기존 명령(`milkbank-setup-tls`, `milkbank-create-admin`, `milkbank-serve`)과 동작이 같아야 한다 — 같은 `main()`을 부른다.
- 배치 파일은 UTF-8(BOM 없음) + 첫 줄 근처 `chcp 65001 >nul`, 항상 자기 폴더로 `cd /d "%~dp0"` 후 실행(데이터가 `data/`에 생기도록).
- 방화벽 규칙을 만들지 않는다. 이 개발 PC에 작업 스케줄러 작업을 실제로 등록하지 않는다(시험은 명령 문자열·드라이런으로).
- 빌드 결과(`server/build/`, `server/dist/`, `*.spec`가 만든 산출물)는 `.gitignore`에 넣는다. `.spec` 파일 자체는 커밋한다.
- 기존 서버 테스트 332개는 그대로 통과(`uv run pytest -W error`). 커밋 끝 줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 실제 서버 데이터(`server/data/demo`, `server/data/milkbank.db`)는 건드리지 않는다.

## Review Focus

1. **설치 폴더 경로에 한글·공백** (예 `C:\모유 관리\모유관리서버`) — 배치 파일과 exe가 그대로 동작. → Task 2 스모크 시험을 그런 경로로.
2. **고정 실행에서 마이그레이션을 못 찾음** — 빈 DB에서 `create-admin`이 0005까지 올려야 한다. → Task 1 스모크 시험.
3. **서버를 두 번 시작** — 포트가 이미 쓰이면 알아보기 쉬운 메시지(로그) 후 종료, 두 번째 창이 조용히 죽지 않게 `서버시작.bat`가 이미 실행 중이면 알려 준다. → Task 2.
4. **`처음설정.bat`를 관리자 권한 없이 실행** — 안내 후 멈추고 아무것도 만들지 않는다. → Task 2.
5. **IP를 잘못 입력** — 다시 묻는다(빈 값·형식 오류). → Task 2.

### Task 1: 하위 명령 실행 파일과 빌드

**Files:**
- Create: `server/src/milkbank/launcher.py`, `server/packaging/milkbank-server.spec`, `server/packaging/build.ps1`, `server/tests/test_launcher.py`
- Modify: `server/pyproject.toml`(스크립트 `milkbank-server = "milkbank.launcher:main"`), `.gitignore`

**Interfaces:**
- Produces: `launcher.main(argv: list[str] | None = None) -> None` — 첫 인자 `setup-tls` / `create-admin` / `serve` / `version`에 따라 기존 `setup_tls.main`, `cli.main`, `serve.main`을 그 뒤 인자로 부른다(`sys.argv` 조정). 인자가 없거나 모르는 명령이면 한국어 사용법을 출력하고 종료 코드 2.
- `build.ps1`: `uv run --with pyinstaller pyinstaller packaging/milkbank-server.spec --noconfirm` → `dist/모유관리서버/`에 exe와 `_internal/`, `packaging/files/` 아래 배치 파일·안내문 복사(Task 2가 채움; 폴더가 비어 있어도 빌드는 성공), `dist/모유관리서버.zip` 생성.
- spec: onedir, 콘솔 exe 이름 `milkbank-server`, `datas`에 `src/milkbank/migrations` 전체, `hiddenimports`에 uvicorn 하위 모듈(`uvicorn.logging`, `uvicorn.loops.auto`, `uvicorn.protocols.http.auto`, `uvicorn.lifespan.on` 등 필요한 것)과 `milkbank.main`.
- [ ] **Step 1: 실패하는 테스트** — `test_launcher.py`: 명령별로 해당 main이 불리고 나머지 인자가 전달됨(monkeypatch), 모르는 명령 → SystemExit(2)와 사용법, `version` → 패키지 버전 출력
- [ ] **Step 2: 실패 확인** → **Step 3: 구현** → **Step 4:** `uv run pytest -W error` 전체 통과
- 데모 자료: `server/scripts/make_demo_db.py <db_path> <accounts_path> [--today YYYY-MM-DD]` (설계 "데모 자료" 항목 그대로). 앱 서비스 함수(`staff`, `patients`, `stock.add_record`, `submissions.submit`)와 `FakeClock`으로 시각을 옮겨 가며 기록을 넣어 잔량·팩·통계가 실제 경로와 같게 한다. 비밀번호는 `secrets`로 만들고 `must_change_password=False`. 시험 `tests/test_demo_db.py`: 만든 DB가 head 버전, 아기 8명, 계정 2개(바로 로그인 가능), 모든 아기에서 `stock.balance == 재고 팩 수`, 부족·0팩 아기 존재, 확인 대기 2건, 계정 파일에 두 비밀번호가 들어 있음.
- `build.ps1`는 기본으로 `dist/모유관리서버-데모/`(+zip)를 만든다: exe·배치·안내문 + `data/milkbank.db`(make_demo_db로 새로 만듦) + 맨 위 `데모계정.txt`. `-Real` 스위치면 데이터 없이 `dist/모유관리서버/`(+zip).
- [ ] **Step 5: 빌드와 스모크 시험** — `powershell -File packaging/build.ps1` → 결과 폴더를 스크래치 임시 위치(경로에 한글·공백 포함)로 복사 → 그 안에서 `milkbank-server.exe setup-tls --host 127.0.0.1 --port 18443` → (데모 폴더이므로 관리자 만들기 없이) `serve`를 백그라운드로 → `https://127.0.0.1:18443/health`가 200(`curl -k`) → 서버 종료 → 임시 폴더 삭제. 결과(크기, 명령 출력)를 보고서에.
- [ ] **Step 6: 커밋** — `feat(server): 다른 PC용 서버 실행 파일 만들기(하위 명령, PyInstaller 빌드)`

### Task 2: 배치 파일, 자동 시작, 안내문

**Files:**
- Create: `server/packaging/files/처음설정.bat`, `서버시작.bat`, `서버중지.bat`, `자동시작해제.bat`, `읽어주세요.txt`
- Modify: `server/README.md`(실행 파일 만들기·옮기기 절), `docs/다음에-이어서.md`는 건드리지 않음(컨트롤러가 함)

**동작:**
- `처음설정.bat` (폴더 맨 위에 `데모계정.txt`가 있으면 5번 관리자 만들기를 건너뛰고 그 파일 내용을 보여 준다)
  1. `net session >nul 2>&1`로 관리자 권한 확인, 없으면 "이 파일을 마우스 오른쪽 → 관리자 권한으로 실행해 주세요" 후 `pause`, 종료(아무것도 만들지 않음)
  2. 이미 `data\tls\server.json`이 있으면 "이미 설정되어 있습니다. 다시 설정하면 모든 기기에서 QR을 다시 찍어야 합니다. 계속할까요? (Y/N)"
  3. PowerShell로 이 PC의 IPv4 목록(가상 어댑터 포함)을 번호와 함께 보여 주고 번호 또는 직접 입력으로 고르게 함. 빈 값·IPv4 형식이 아니면 다시 물음
  4. `milkbank-server.exe setup-tls --host <IP>`
  5. 관리자 아이디 입력(빈 값이면 `admin`) → `create-admin --username <id> --name 관리자` → 임시 비밀번호를 크게 보여 주고 "적어 두세요"
  6. 작업 스케줄러 등록: `schtasks /Create /TN "MilkbankServer" /TR "\"<폴더>\서버시작.bat\" /background" /SC ONSTART /RU SYSTEM /RL HIGHEST /F`
  7. `서버시작.bat /background` 실행, 몇 초 뒤 `https://<IP>:8443/health` 확인 결과 표시(PowerShell, 인증서 검사 끔)
  8. 방화벽 안내(인바운드 규칙 → 포트 TCP 8443 → 개인 네트워크) 출력, `data\tls\server-qr.png` 열기
- `서버시작.bat [/background]`: 8443(또는 server.json의 포트)이 이미 쓰이면 "서버가 이미 실행 중입니다" 후 종료. `/background`면 창 없이(`start "" /b` 또는 PowerShell `Start-Process -WindowStyle Hidden`) `milkbank-server.exe serve >> data\logs\server.log 2>&1`, 아니면 현재 창에서 실행
- `서버중지.bat`: `milkbank-server.exe` 프로세스 종료(`taskkill /IM milkbank-server.exe /F`) 후 결과 표시
- `자동시작해제.bat`: 관리자 권한 확인 후 `schtasks /Delete /TN "MilkbankServer" /F`
- `읽어주세요.txt`: 옮기기(폴더째 복사), 처음 설정, 방화벽, 핸드폰 앱 설치·QR 등록·'근처 기기' 권한, 시작/중지/자동 시작 해제, 백업(`data\backups`), 로그 위치, 개인정보 주의(시험에는 가짜 자료만), 서버 PC IP를 고정해 달라는 안내
- [ ] **Step 1: 시험** — 배치 파일은 자동 시험이 어려우므로, 각 파일의 핵심 명령을 `echo`로 바꿔 보는 드라이런 방식(환경 변수 `MILKBANK_DRYRUN=1`이면 schtasks·taskkill·서버 실행 대신 명령을 출력)으로 Review Focus 3–5를 확인한다. 드라이런 출력과 실제 실행(관리자 권한 없이 실행 → 멈춤, 서버 시작/중지)을 보고서에.
- [ ] **Step 2: 다시 빌드** 후 결과 폴더를 한글·공백 경로에 복사해 `서버시작.bat`(창 모드) → health 200 → `서버중지.bat` → 종료 확인. `처음설정.bat`는 관리자 권한이 없는 상태로 실행해 멈추는지만 확인(이 PC에 작업 스케줄러를 등록하지 않음).
- [ ] **Step 3: README** — `server/README.md`에 "다른 PC에 설치(실행 파일)" 절: 만들기(`packaging/build.ps1`), 옮기기, `처음설정.bat`
- [ ] **Step 4: 커밋** — `feat(server): 서버 PC용 처음설정·시작·중지·자동 시작 배치 파일과 안내문`
