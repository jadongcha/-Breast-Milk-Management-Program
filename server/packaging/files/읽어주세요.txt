모유 관리 서버 (서버 PC용 폴더)
==============================

이 폴더에는 파이썬이나 다른 프로그램을 따로 설치하지 않아도 되는 서버가 들어 있습니다.
tools 폴더는 .bat 파일이 쓰는 내부 파일이니 지우거나 옮기지 마세요.

1. 옮기기
---------
- 이 폴더를 통째로 서버로 쓸 PC의 C:\MilkbankServer (또는 C:\Program Files\MilkbankServer)로 옮깁니다.
  압축 파일(.zip)이면 풀면 같은 이름의 폴더가 한 번 더 생깁니다. 안쪽 폴더(milkbank-server.exe가 보이는 폴더)를 옮기세요.
- 사용자 프로필 안(C:\Users\... 아래의 바탕화면, 다운로드, 문서 등)과 OneDrive 폴더에서는 처음설정.bat가 설정을 거부합니다.
  그런 곳은 아래 "폴더 잠금"이 소용없고 파일이 사라질 수 있기 때문입니다. 먼저 C:\MilkbankServer 같은 곳으로 옮기세요.
  C:\ 바로 아래에 새로 만든 폴더는 기본적으로 모든 사용자가 고칠 수 있으므로, 처음설정.bat가 아래 "폴더 잠금"을 해 줍니다.
- 옮긴 위치를 나중에 바꾸면 자동 시작이 깨집니다. 바꿨다면 처음설정.bat를 다시 실행해 [1] 자동 시작만 다시 등록을 고르세요
  (인증서는 그대로라서 기기에서 QR을 다시 찍을 필요가 없습니다).
- 서버 PC의 IP 주소를 바뀌지 않게 고정해 주세요(전산팀에 요청: 공유기/DHCP 예약).
  IP가 바뀌면 핸드폰이 서버를 찾지 못하고, 모든 기기에서 QR을 다시 찍어야 합니다.

1-1. 보안 경고가 뜰 때 (Windows 보호, 백신)
-------------------------------------------
이 프로그램은 코드 서명이 없어서, 메신저·메일·인터넷으로 받은 파일이면 Windows가 경고할 수 있습니다.
- 압축 파일(.zip)을 풀기 전에: 압축 파일을 마우스 오른쪽 → 속성 → 맨 아래 "차단 해제"를 체크 → 확인. 그다음 풉니다.
  (처음설정.bat도 폴더 안 파일의 차단 표시를 자동으로 지웁니다.)
- "Windows의 PC 보호" 파란 창이 뜨면: "추가 정보" → "실행"을 누릅니다.
- 파일 하나가 안 열리면: 그 파일을 마우스 오른쪽 → 속성 → "차단 해제"를 체크합니다.
- 새 Windows 11에서 "스마트 앱 컨트롤"이 켜져 있으면 서명 없는 프로그램을 아예 막습니다. 설정 → 개인 정보 및 보안 →
  Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 끄거나 전산팀에 문의하세요(끄면 보안이 약해지므로 전산팀 판단에 따르세요).
- 백신(V3 등)이 milkbank-server.exe를 지우거나 막으면: 이 폴더 전체를 백신의 예외(검사 제외) 목록에 넣어 달라고 전산팀에 요청하세요.
- "스크립트를 실행할 수 없습니다"라는 PowerShell 오류가 나오면 병원 보안 정책이 막는 것이므로 전산팀에 문의하세요.

2. 처음 설정 (한 번만)
----------------------
- 처음설정.bat 를 더블클릭합니다. 관리자 권한이 필요하므로 "사용자 계정 컨트롤" 창이 뜨면 "예"를 누릅니다
  ("예"를 누르지 않으면 설정은 시작되지 않습니다. 마우스 오른쪽 → 관리자 권한으로 실행해도 됩니다).
- 화면 안내대로 이 PC의 IP를 고릅니다(병원 내부망 주소). 고른 주소의 네트워크 종류(공용/개인/도메인)가 함께 표시됩니다.
  "공용"이라고 나오면 핸드폰이 접속하지 못할 수 있습니다: 설정 → 네트워크 및 인터넷 → 이더넷(또는 Wi-Fi) → 이 연결의 속성 →
  네트워크 프로필 유형을 "개인"으로 바꾸세요. 병원 도메인에 연결된 PC(도메인)는 전산팀이 정하므로 전산팀에 문의하세요.
- 서버 등록 QR이 만들어집니다. 일반 사용자도 열 수 있게 폴더 맨 위에 서버등록QR.png로 복사됩니다.
  출력해서 신생아실에 보관하세요.
- 관리자 아이디를 정하면 임시 비밀번호가 나옵니다. 꼭 적어 두고, 처음 로그인한 뒤 바꾸세요.
  (데모 폴더는 관리자를 새로 만들지 않고 데모계정.txt의 계정을 씁니다.)
- 폴더 잠금: 처음설정.bat가 이 폴더의 권한을 바꿉니다. 관리자와 SYSTEM만 파일을 바꿀 수 있고, 일반 사용자는
  프로그램 파일을 읽고 실행만 할 수 있으며, data 폴더(DB, 개인키, 백업, 로그)는 관리자만 읽을 수 있습니다.
  (PC가 켜질 때 SYSTEM 권한으로 도는 파일을 일반 사용자가 고쳐 악용하는 것을 막기 위해서입니다.)
  따라서 서버시작.bat, 서버중지.bat 등은 관리자 권한이 필요하며, 일반 사용자가 실행하면 "사용자 계정 컨트롤" 창이 뜹니다.
- PC가 켜지면 서버가 저절로 시작되도록 등록하고, 서버도 그 등록된 작업으로 바로 켭니다(로그아웃해도 꺼지지 않습니다).
- 이 PC의 8443 포트를 다른 모유 서버(데모 폴더, 이전 버전 등)가 이미 쓰고 있으면 설정이 멈춥니다. 그 폴더에서
  서버중지.bat 와 자동시작해제.bat 를 실행한 뒤 다시 하세요.
- 처음설정.bat를 이미 설정된 폴더에서 다시 실행하면 [1] 자동 시작만 다시 등록하고 서버 켜기 / [2] 처음부터 다시 설정 / [N] 취소를 묻습니다.
  [1]은 인증서를 그대로 두므로 기기에서 QR을 다시 찍지 않아도 됩니다. [2]는 서버 PC의 IP를 바꿀 때 고릅니다.
  IP가 바뀌면 모든 핸드폰·기기에서 서버 등록 QR을 다시 찍어야 합니다.

3. 방화벽 (전산팀 또는 직접)
---------------------------
이 프로그램은 방화벽 규칙을 만들지 않습니다. 직접 허용해야 핸드폰이 접속할 수 있습니다.
- 시작 메뉴 -> "고급 보안이 포함된 Windows Defender 방화벽"
- 인바운드 규칙 -> 새 규칙 -> 포트 -> TCP, 특정 로컬 포트 8443
- 연결 허용 -> 이 PC가 실제로 쓰는 네트워크 종류에 체크 -> 이름 입력 후 마침
  병원 내부망이 "도메인"으로 잡혀 있으면 도메인, "개인"이면 개인에 체크합니다(공용은 체크하지 마세요).
  처음설정.bat가 마지막에 보여 주는 네트워크 종류를 확인하세요. 모르겠으면 전산팀에 문의하세요.
- 서버를 켤 때 "Windows 보안 경고(Windows Defender 방화벽이 이 앱의 일부 기능을 차단했습니다)" 창이 뜨면
  "개인 네트워크"와 "도메인 네트워크"를 체크하고 "액세스 허용"을 누르세요. "취소"를 누르면 이 프로그램을 막는 규칙이 생겨
  핸드폰이 접속하지 못합니다. (자동 시작 작업으로 켜면 이 창은 보통 뜨지 않습니다.)

4. 핸드폰 앱
-----------
- 앱(APK)을 핸드폰에 설치합니다(출처를 알 수 없는 앱 설치를 허용해야 할 수 있습니다).
- 앱에서 서버 등록 QR을 찍어 서버를 등록합니다. 핸드폰이 병원 내부망(Wi-Fi)에 연결되어 있어야 합니다.
- 앱이 "근처 기기" 권한을 물으면 허용합니다(라벨 프린터 연결 등에 필요).
- 그 다음 서버 관리자 아이디로 로그인합니다.

5. 켜기, 끄기, 자동 시작
------------------------
네 파일 모두 관리자 권한이 필요합니다. 일반 사용자가 더블클릭하면 "사용자 계정 컨트롤" 창이 뜨고, "예"를 누르면 됩니다.
- 서버시작.bat      서버를 켭니다. 자동 시작이 등록된 폴더에서는 그 작업으로 켜서 창을 닫거나 로그아웃해도 계속 켜져 있습니다.
                    이미 켜져 있으면 "서버가 이미 실행 중입니다"라고 알려 주고, 다른 프로그램이 포트를 쓰고 있으면 알려 줍니다.
- 서버중지.bat      켜진 서버를 끕니다. 주의: 이 PC에서 켜져 있는 milkbank-server.exe를 모두 끕니다(다른 폴더의 서버도 함께 꺼집니다).
- 자동시작해제.bat  PC가 켜질 때 서버가 저절로 시작되는 것을 해제합니다.
                    다시 켜고 싶으면 처음설정.bat를 다시 실행합니다.
- 서버를 끄거나 PC를 끄면 핸드폰 앱은 쓸 수 없습니다.

6. 백업과 로그
--------------
- 데이터는 모두 data 폴더에 있습니다(DB, 인증서, 백업, 로그). data 폴더는 이 PC 밖으로 복사하지 마세요.
- 서버를 새 버전으로 바꿀 때 자동으로 만든 백업은 data\backups 에 있습니다.
  백업에는 환자·보호자 개인정보가 들어 있어 30일이 지나면 서버가 자동으로 지웁니다.
- 서버 기록은 data\logs\server.log 에 쌓입니다. 문제가 생기면 이 파일을 확인하세요.
  (파일은 계속 커집니다. 서버를 끈 뒤 지워도 됩니다.)

6-1. 새 버전으로 바꾸기
-----------------------
이미 운영 중인 폴더를 새 버전으로 바꿀 때는 새 폴더에 새로 설정하지 말고(빈 DB로 시작하고 환자 자료가 옛 폴더에 남습니다) 이렇게 합니다.
1) 서버중지.bat 를 실행해 서버를 끕니다(켜진 채로 복사하면 파일이 섞여 서버가 망가집니다).
2) 새 버전 폴더의 파일을 운영 폴더에 덮어 씁니다(폴더가 잠겨 있으므로 관리자 권한으로 복사합니다). 단 data 폴더는 절대 덮어쓰거나 지우지 마세요.
   (milkbank-server.exe, _internal, tools 폴더와 .bat, .txt 파일만 복사합니다.)
   새 버전은 "데모"가 아닌 실제 운영용 빌드여야 합니다. 데모 빌드를 덮어쓰면 데모 자료가 섞입니다.
   실제 운영용 빌드에는 data 폴더가 들어 있지 않아 통째로 덮어써도 DB는 그대로입니다.
3) 서버시작.bat 를 실행합니다. DB는 서버가 켜질 때 자동으로 새 버전에 맞게 바뀌고, 그 전에 백업이 data\backups 에 만들어집니다.

7. 개인정보 주의, 데모에서 실제 운영으로
-----------------------------------------
- 이 폴더가 "데모" 이름이면 가짜 환자 자료가 들어 있습니다. 시험할 때는 가짜 자료만 쓰세요.
- 실제 환자 정보는 실제 운영용 폴더(이름에 "데모"가 없는 것)에서만 입력하세요.
- 시험을 끝내고 실제 운영으로 옮길 때:
  1) 데모 폴더에서 자동시작해제.bat 를 실행합니다.
  2) 이어서 같은 폴더에서 서버중지.bat 를 실행합니다(이 PC의 모든 milkbank-server.exe가 꺼집니다).
  3) 데모 폴더 전체를 지웁니다(관리자 권한이 필요할 수 있습니다). 서버가 켜진 채로는 지워지지 않습니다.
  4) 실제 운영용 폴더를 C:\MilkbankServer 에 놓고 처음설정.bat 를 실행합니다.
